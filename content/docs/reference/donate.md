# Donate

Vitruvian is developed by volunteers in their spare time. If you find the project useful and want to support its development, donations are welcome.

Support VitruvianOS through **[GitHub Sponsors](https://github.com/sponsors/VitruvianOS)**.

Other ways to help:

- **Testing** — run latest builds and [report issues](https://github.com/VitruvianOS/Vitruvian/issues)
- **Contributing code** — see the [coding guidelines](../../development/coding-guidelines/) and open a pull request
- **Spreading the word** — tell others about the project
